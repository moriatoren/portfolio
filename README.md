### Design Features
- **Responsive Design:** Mobile-friendly layout
- **Modern UI:** Gradient colors (blue/purple theme)
- **Game Cards:** Display game icons with iOS/Android download links
- **Profile Section:** Square profile picture with rounded corners
- **Article Cards:** Publication info with links to articles
- **Resume Section:** Detailed work experience and skills
- **Smooth Scrolling:** Navigation with smooth scroll effects

### Styling Details
- Primary Color: #667eea (Blue)
- Secondary Color: #764ba2 (Purple)
- Profile Picture: 230px square with rounded corners (border-radius: 10px)
- Game Icons: Auto height with contain object-fit to preserve aspect ratio
- Responsive Grid: auto-fit columns with minmax(240px, 1fr)
- Button Alignment: Fixed at bottom of cards using flexbox

## How to Update

### Add/Edit Games
1. Update game card in `index.html` with new image path
2. Update iOS/Android links
3. Commit and push to GitHub

### Update Articles
1. Find article card in `index.html` (around line 422)
2. Update title, description, and link
3. Commit and push

### Update Resume/Experience
1. Edit resume section in `index.html`
2. Add new job, skills, or achievements
3. Commit and push

### Styling Changes
1. Edit `style.css` for design updates
2. Test locally before committing
3. Push to GitHub
